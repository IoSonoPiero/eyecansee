What the screenshots and the GIF show (grid.png, viewer.png, mtp-open.gif and the site's mtp-open.mp4
and mtp-open-poster.jpg: a POCO X7 Pro's folder DCIM/EyeCanSee-demo, made of the files below;

mtp-open.gif (800 x 533, 10 fps, 10 s) and the site's mtp-open.mp4 (800 x 534): the phone's DCIM
folder, then a double click on EyeCanSee-demo and its thumbnails. Dark theme, 1200 x 800, recorded
by EyeCanSee itself, the pointer drawn afterwards. The home folder shown (/home/demo) is a test one,
with no disks.

devices.png: the 13 photos below in the folder Photos of a test FTP server on the same computer,
saved as "NAS" (nas.example, user "demo"); in the left panel a POCO X7 Pro and a second
saved server "Storage Box" (storage.example), not opened. servers.png: the server manager with
these two example servers and a master password. rotate.png: Wilderness.jpg. Server names, hosts
and users are made up for the screenshots. video-convert.png (1600 x 800): 9 of the photos and the 4
videos below in a folder on disk, sorted by date, the videos selected.

guide.webp, bookmarks.webp (1200 x 800) and the site's guide, guide-search, bookmarks and
open-location (.png 1200 x 800, .webp 800 x 533): made with tools/shots.sh, scenes in
tools/shots/site/. Dark theme, English. The home folder (/home/demo), the disks BACKUP and USB STICK
and the servers (photos.example.com, media.example.com, user "demo") are made up for the pictures.

browse.gif (800 x 533, 10 fps, 31 s) and the site's browse.mp4 (800 x 534) and browse-poster.jpg:
a folder Sample photos on disk with the 13 photos below, Bees on flowers.webm, Earth from space.webm,
Flowers.webm and Avocado.glb (below). Quebec City.jpg in the viewer, zoomed in and back; the image
editor with an arrow, a text and a box covering the parked cars, then Save copy; Iceberg.jpg,
Moth.jpg and Orchid.jpg converted to WebP inside 1920 x 1080 with Convert and resize; Avocado.glb
turned in the 3D viewer. Dark theme, 1200 x 800, recorded by EyeCanSee itself, the pointer drawn
afterwards. The home folder shown (/home/demo) is a test one, with no disks.

model-3d.png: Avocado.glb in the 3D viewer, from the Khronos glTF Sample Assets
(https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Avocado): the model and its
textures CC0 1.0 (Microsoft), as its LICENSE.md says.

cad-drawing.png: Flat.dwg, a small flat plan drawn for EyeCanSee with ezdxf 1.4.5 (layers for
walls, doors, windows, furniture, dimensions and texts; linear dimensions) and saved as DWG by
EyeCanSee's Export drawing: free to use for any purpose.

Both taken in a home folder made for the screenshots (/home/demo), 1200 x 800, dark theme;
model-3d.png on a screen at 167 % (2000 x 1333) and reduced to 1200 x 800, to show the viewer at
the screen's refresh rate.

editor.png: Wilderness.jpg (below) in the image editor, with a speech bubble, an ellipse, two
numbered steps joined by a dashed line, a text and a stamp; 1200 x 800, dark theme, taken by
EyeCanSee itself, the objects placed by a temporary debug change instead of the mouse.
