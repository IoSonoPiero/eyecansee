# Picture credits

The pictures of the guide (`docs/help/img/*.webp`) are screenshots of EyeCanSee, taken by the program itself (`tools/shots.sh`, the scenes in `tools/shots/`) in a home folder made for them. Every photo, video, 3D model and drawing they show, thumbnails in the grids included, is listed here with its author, licence and source. None of these licences asks for attribution; the authors are named as a courtesy.

Licences, checked on 2026-11-10 on the pages linked below:

- **PD**: public domain.
- **CC0**: [Creative Commons Zero 1.0](https://creativecommons.org/publicdomain/zero/1.0/), public domain dedication.

## Made up for the pictures

The home folder (`/home/demo`) and its folder names, the servers "Photo archive" and "Home NAS" (`example.com`, user `demo`), the USB stick "USB STICK" and the external disk "BACKUP" (folders in memory that the program takes for disks), the bookmarks and the dates of the files.

The icons of the interface are part of EyeCanSee: [Lucide](https://lucide.dev), ISC licence (`assets/icons/lucide/LICENSE-lucide.txt`).
