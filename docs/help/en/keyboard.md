# Keyboard shortcuts

All the keys of EyeCanSee, grouped by where they work. The menus show the key next to each item, and pointing at a toolbar button shows its name and key. In the grid, in the viewer, in the editor and in Find duplicates the **Keys** button at the bottom right lists the keys of what you are looking at.

## Everywhere

| Key | Action |
|---|---|
| F1 | Open this guide on the page about what you are doing; again to close it |
| Esc twice, quickly | Close this guide, with the pointer on it or while typing in its search field (a single Esc only leaves the field). When the guide is open over a window, a message for instance, it closes wherever the pointer is, and the window stays open |
| Tab, **Shift + Tab** (this guide open) | Go through the search field, the contents and the page of this guide; they do not reach the grid or the viewer under it |

## In the grid and the viewer

| Key | Action |
|---|---|
| F5 | Read the open folder again, and only that one (in the viewer, the open image stays shown) |
| F6 | Move the keyboard to **Cancel** of a job under way: a copy, a conversion or an export of 3D models (with more than one, F6 again goes to the next); **Enter** or **Space** stops it |
| F11 | Full screen and back; in the viewer only the image is shown, without menus or bars |
| **Ctrl + R**, **Ctrl + Shift + R** | Turn the picture 90° clockwise, anticlockwise: in the viewer you see it before saving, in the grid the selected pictures are saved after asking (see [Rotating and flipping](rotate.md)) |
| **Ctrl + Z**, **Ctrl + Y** | In the viewer: undo, redo an unsaved turn or flip |
| **Ctrl + Shift + D** | Bookmarks: the list opens; ↓ enters it, Enter opens the bookmark chosen (see [Bookmarks](bookmarks.md)) |

In windows that report how an operation went, **Enter** or **Esc** closes the window; after its buttons, **Tab** reaches the small copy icon (**Copy the message**), and **Enter** on it copies the text. In windows that ask for a choice, one button is highlighted when the window opens: the main choice, or **Cancel** when the main choice cannot be undone (deleting for good or in a trash, deleting folders, saving over many pictures or over an original deleted for good, trusting a new server, deleting a saved server or the master password) or would lose data. **Tab**, **Shift + Tab** and the arrows move between the buttons and the other controls of the window, in their order on screen. **Enter** or **Space** presses the highlighted one (on a check box, a list or a link, they tick the box, open the list or open the link; in an open list, the arrows and **Enter** choose, and **Esc** closes only the list). **Esc** cancels. When a name is already taken, **Keep both** is highlighted. With this guide open over the window, **Esc** goes to the guide first (two close it, as everywhere), **Enter** does not answer the window, and what you type in the guide's search field stays there.

In **About EyeCanSee** nothing is highlighted when it opens: **Enter** or **Esc** closes it. **Tab** and **Shift + Tab** go through its links and **Copy (to report a problem)**; **Enter** or **Space** opens or presses the highlighted one.

In **New image** and **Options**, **Tab** and **Shift + Tab** cycle through their controls: from the last one back to the first, and the other way round; they never reach the menus or the grid under the window. The same applies in **Server manager** and in the folder picker of **Save as** and **Convert**: **Tab** and the arrows go through places, folders and buttons, and **Enter** on a folder goes into it. In **Open location**, **Bookmarks > Configure…**, the master password window, **Convert** and the editor's **Resize**, **Tab** with nothing highlighted goes to their fields, lists and buttons, and the arrows move between them.

In a drop-down list (a format, a size, a unit) **Space** or **Enter** opens it with the keyboard on the entry chosen, the arrows go on from there, **Enter** or **Space** chooses an entry and closes the list, and **Esc** closes it without changing the choice.

In the tip at startup, → and ← show the next and the previous tip. **Close** is highlighted when it opens. **Tab** and **Shift + Tab** move between **Read more in the guide**, **Back**, **Next**, **Close** and **Don't show at startup**, in their order on screen. **Enter** or **Space** presses the highlighted one, and **Esc** closes the tip. The other keys do nothing, except **F1**, which opens this guide (see [Getting started](start.md)).

In the first-start window, each page opens with its main button highlighted: **Next**, then **Done**, or **Download** when an add-on is ticked. On the desktop icon page, **Next** pressed before **Yes** or **No** only asks you to choose, and after the answer **Next** is highlighted again. **Enter** or **Space** presses the highlighted button. **Tab**, **Shift + Tab** and the arrows move between the buttons, in their order on screen, and also reach the choices on the page. **Esc** closes the window. When it asks before closing, **Download and close** is highlighted and **Esc** goes **Back**.

## In the grid

| Key | Action |
|---|---|
| Arrows | Move the selection (the first press selects the first item; ← on the first item goes to **..**) |
| **Shift + arrows**, **Shift + Home**, **Shift + End** | Extend the selection |
| Home, End | First, last item |
| Enter | Open the folder or the image; on **..** go up |
| Backspace | Parent folder |
| **Ctrl + A** | Select everything in the folder |
| Tab | Next item; from the last one to the devices |
| **Shift + Tab** | Previous item; from the first one to the box of a copy or of Convert under way, if there is one, otherwise to the folder open on the left |
| **Ctrl + C**, **Ctrl + X**, **Ctrl + V** | Copy, cut, paste (see [Copying and moving](copy-move.md)) |
| F2 | Rename (see [Renaming and new folders](rename.md)) |
| **Ctrl + Shift + N** | New folder |
| Del | Delete (see [Deleting and the trash](delete.md)) |
| **Shift + Del** | Delete for good |
| **Ctrl + N** | New image (see [New image](new-image.md)) |
| **Ctrl + E** | Edit image (see [Editing an image](editor.md)) |
| **Ctrl + B** | Convert… (see [Converting and resizing images](convert.md)) |
| **Ctrl + D** | Find duplicates (see [Finding duplicates](duplicates.md)) |
| **Shift + F5** | Make all the thumbnails in the folder again |

With the mouse: **Ctrl + click** adds or removes an item, **Shift + click** selects from the last item clicked to this one, and dragging on the grid draws a rectangle that selects what it touches (with Ctrl it adds to the selection). See [Selecting files](selection.md).

## In the folder tree and the devices

| Key | Action |
|---|---|
| ↓, ↑ | Next, previous folder |
| → | Expand the folder; if already expanded, go to its first subfolder |
| ← | Collapse the folder; if already collapsed, go to its parent |
| Backspace | Parent folder |
| Tab | Next folder; from the last one to the box of a copy or of Convert under way, if there is one (its **Cancel**: **Enter** or **Space** presses it, **Tab** goes on to the grid, **Shift + Tab** back to the folders), otherwise to the grid |
| **Shift + Tab** | Previous folder; from the first one to the last device |

In the **Devices** block: ↓ and ↑ change device (↓ on an expanded device enters its first folder), → and ← expand and collapse it, **Enter** opens it on the right, **Tab** goes to the next one and from the last one to the computer's folders, **Shift + Tab** to the previous one and from the first one to the last item of the grid.

## In the viewer: images

| Key | Action |
|---|---|
| Tab, **Shift + Tab** | Go through the buttons of the bars: **Enter** and **Space** press the highlighted button, the other keys of the viewer work as always (← and → change the image, **Esc** goes back to the grid); on the zoom slider ← and → change the zoom |
| →, Space, Page Down | Next image |
| ←, Backspace, Page Up | Previous image |
| Home, End | First, last image |
| Space (on an animation) | Pause and play it |
| Space (on a motion photo) | Play its video |
| Page Down, Page Up (on a TIFF with pages) | Next, previous page |
| P (on a 360° panorama) | Flat picture, and back to the 360° view |
| Esc | Back to the grid (in full screen it first leaves full screen); closes EyeCanSee when **The window's ✕ goes back to the grid** is off in the [Options](options.md) |
| Double click | Back to the grid, or full screen and back, as set in the [Options](options.md) |
| Enter | Back to the grid, even when Esc closes EyeCanSee |
| + and − (or the mouse wheel) | Zoom in and out |
| 0 | Fit the image to the window |
| 1 | 100%: one image pixel per screen pixel |
| **Ctrl + S** | Save the turned image over the original |
| **Ctrl + Shift + S** | Save as (see [Save as](save-as.md)) |
| **Ctrl + E** | Edit image |
| **Ctrl + C**, **Ctrl + X** | Copy or cut the image shown, to paste it in a folder from the grid (**Ctrl + V** does nothing in the viewer) |
| F2, Del, **Shift + Del** | Rename and delete, as in the grid |

The mouse wheel zooms around the pointer, + and − around the middle of the window; Ctrl and the wheel always zoom, even when the wheel is set to change image (see [Options](options.md)).

## In the viewer: videos and audio

| Key | Action |
|---|---|
| Space | Play and pause |
| **Ctrl + ←**, **Ctrl + →** | 5 seconds back, forward |
| **.**, **,** | One frame forward, back (paused; not on an audio file) |
| **Ctrl + R**, **Ctrl + Shift + R** | Turn the video right, left (see [Rotating and flipping](rotate.md)) |
| **Ctrl + Z**, **Ctrl + Y** | Undo, redo a turn not saved |
| **Ctrl + S** | Save the turn of the video |
| ↑, ↓ (or the mouse wheel on the video) | Volume up, down |
| M | Audio off and on |
| **Ctrl + Shift + S** | Pause and save the frame shown as a picture (see [Playing videos](video.md)) |
| →, Page Down | Next item |
| ←, Backspace, Page Up | Previous item |
| Home, End | First, last item |
| Esc | Back to the grid, or closes EyeCanSee as above |
| Enter | Back to the grid |

## In the viewer: 3D models

| Key | Action |
|---|---|
| Arrows | Turn the model (hold them down to keep turning) |
| Shift and drag, or drag with the middle button | Move the model in the window |
| + and − (or the mouse wheel) | Zoom in and out |
| 0 | Back to the starting view |
| M | Measure: size, surface, volume, and the distance between two points clicked (Backspace removes the last point, Esc clears the points and then closes Measure, **Ctrl + C** copies the results, M again closes it) |
| S | Section: cut the model with a plane (X, Y, Z its axis; **Alt + wheel**, comma and full stop move it; F keeps the other side) |
| Page Down, Space | Next item |
| Page Up, Backspace | Previous item |
| Home, End | First, last item |
| F2, Del, **Shift + Del** | Rename and delete, as in the grid |
| **Ctrl + Shift + S** | Save the model as it is shown, as an image (**Ctrl + S**, which saves over the original, is greyed out on a model) |
| Esc | Back to the grid, or closes EyeCanSee as above |
| Enter | Back to the grid, even while measuring |

## In the viewer: CAD drawings

| Key | Action |
|---|---|
| + and − (or the mouse wheel) | Zoom in and out; drag to move |
| 0 | The whole drawing |
| →, Space, Page Down | Next file |
| ←, Backspace, Page Up | Previous file |
| Home, End | First, last file |
| L, **Shift + L** | Next, previous layout |
| **Ctrl + L** | Layers panel |
| M | Measure (then D distance, A area, G angle; Enter closes an area, Backspace removes the last point, Esc clears the points and then closes Measure, **Ctrl + C** copies the results, M again closes it) |
| N, **Shift + N** | Next, previous change, when comparing two drawings |
| **Ctrl + Shift + S** | Save the drawing as an image |
| F2, Del, **Shift + Del** | Rename and delete, as in the grid |
| Esc | Back to the grid, or closes EyeCanSee as above |
| Enter | Back to the grid; while measuring it closes an area, and does nothing when there is none to close |

| **Ctrl + Shift + S** | Save as |
| Esc | One step at a time: stops what is under way, ends the text, deselects; then closes the editor |

See [Editing an image](editor.md).

## In other pages

- **Save as**: **Tab** and **Shift + Tab** go through its controls, the arrows move between them, **Enter** or **Space** presses the highlighted one; **Esc** closes the page without saving.
- **Find duplicates**: **↑** and **↓** move between the copies, **Space** ticks or unticks, **Esc** closes. Enter does not delete. **Tab** goes to the controls of the page; there the arrows move between them.
