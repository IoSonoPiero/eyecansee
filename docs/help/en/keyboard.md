# Keyboard shortcuts

Every key of EyeCanSee, by place. The menus show the key next to each item, and pointing at a toolbar button shows its name and key. In the viewer and in the editor the **Keys** button on the right of the status bar lists the keys of what you are looking at.

## Everywhere

| Key | Action |
|---|---|
| F1 | Open this guide on the page about what you are doing; again to close it |
| Esc twice, quickly | Close this guide, with the pointer on it or while typing in its search field (one Esc only leaves the field) |

## In the grid and the viewer

| Key | Action |
|---|---|
| F5 | Read the folders again (in the viewer it stays on the open image) |
| F11 | Full screen and back; in the viewer only the image is shown, without menus or bars |
| Ctrl+R, Ctrl+Shift+R | Turn the picture 90° clockwise, anticlockwise: in the viewer you see it before saving, in the grid the selected pictures are saved after asking (see [Rotating and flipping](rotate.md)) |
| Ctrl+Shift+D | Bookmarks: the list opens; ↓ enters it, Enter opens the bookmark chosen (see [Bookmarks](bookmarks.md)) |

In the windows that tell how an operation went, **Enter** or **Esc** closes them; in those that ask for a choice, **Enter** confirms and **Esc** cancels. Two exceptions: a deletion that includes a folder (there Enter cancels too) and turning or flipping pictures in the grid (Enter does not confirm).

## In the grid

| Key | Action |
|---|---|
| Arrows | Move the selection (the first press selects the first item; left from the first item goes to **..**) |
| Shift+arrows | Extend the selection |
| Home, End | First, last item |
| Enter | Open the folder or the image; on **..** go up |
| Backspace | Parent folder |
| Ctrl+A | Select everything in the folder |
| Tab | Next item; from the last one to the devices |
| Shift+Tab | Previous item; from the first one to the folder open on the left |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste (see [Copying and moving](copy-move.md)) |
| F2 | Rename (see [Renaming and new folders](rename.md)) |
| Ctrl+Shift+N | New folder |
| Del | Delete (see [Deleting and the trash](delete.md)) |
| Shift+Del | Delete for good |
| Ctrl+N | New image (see [New image](new-image.md)) |
| Ctrl+E | Edit image (see [Editing an image](editor.md)) |
| Ctrl+B | Convert… (see [Converting and resizing images](convert.md)) |
| Ctrl+D | Find duplicates (see [Finding duplicates](duplicates.md)) |
| Shift+F5 | Make all the thumbnails of the folder again |

With the mouse: **Ctrl+click** adds or removes an item, **Shift+click** selects from the last item clicked to this one, and dragging on the grid draws a rectangle that selects what it touches (with Ctrl it adds to the selection). See [Selecting files](selection.md).

## In the folder tree and the devices

| Key | Action |
|---|---|
| ↓, ↑ | Next, previous folder |
| → | Expand the folder; if already expanded, go to its first subfolder |
| ← | Collapse the folder; if already collapsed, go to its parent |
| Backspace | Parent folder |
| Tab | Next folder; from the last one to the grid |
| Shift+Tab | Previous folder; from the first one to the last device |

In the **Devices** block: ↓ and ↑ change device (↓ on an expanded device enters its first folder), → and ← expand and collapse it, **Enter** opens it on the right, **Tab** goes to the next one and from the last one to the computer's folders, **Shift+Tab** to the previous one and from the first one to the last item of the grid.

## In the viewer: images

| Key | Action |
|---|---|
| →, Space, Page Down | Next image |
| ←, Backspace, Page Up | Previous image |
| Home, End | First, last image |
| Space (on an animation) | Pause and play it |
| Space (on a motion photo) | Play its video |
| Page Down, Page Up (on a TIFF with pages) | Next, previous page |
| Esc | Back to the grid (in full screen it first leaves full screen) |
| + and − (or the mouse wheel) | Zoom in and out |
| 0 | Fit the image to the window |
| 1 | 100%: one image pixel per screen pixel |
| Ctrl+S | Save the turned image over the original |
| Ctrl+Shift+S | Save as (see [Save as](save-as.md)) |
| Ctrl+E | Edit image |
| Ctrl+C, Ctrl+X | Copy or cut the image shown, to paste it in a folder |
| F2, Del, Shift+Del | Rename and delete, as in the grid |

The mouse wheel zooms around the pointer, + and − around the middle of the window; Ctrl and the wheel always zoom, also when the wheel is set to change image (see [Options](options.md)).

## In the viewer: videos and audio

| Key | Action |
|---|---|
| Space | Play and pause |
| Ctrl+←, Ctrl+→ | 5 seconds back, forward |
| ↑, ↓ (or the mouse wheel on the video) | Volume up, down |
| M | Audio off and on |
| →, Page Down | Next item |
| ←, Backspace, Page Up | Previous item |
| Home, End | First, last item |
| Esc | Back to the grid |

## In the viewer: 3D models

| Key | Action |
|---|---|
| Arrows | Turn the model (hold them down to keep turning) |
| Shift and drag, or drag with the middle button | Move the model in the window |
| + and − (or the mouse wheel) | Zoom in and out |
| 0 | Back to the starting view |
| Page Down, Space | Next item |
| Page Up, Backspace | Previous item |
| Ctrl+Shift+S | Save the model as it is shown, as an image (Ctrl+S, which saves over the original, is greyed out on a model) |
| Esc | Back to the grid |

## In the viewer: CAD drawings

| Key | Action |
|---|---|
| + and − (or the mouse wheel) | Zoom in and out; drag to move |
| 0 | The whole drawing |
| ←, → | Previous, next file |
| L, Shift+L | Next, previous layout |
| Ctrl+Shift+S | Save the drawing as an image |
| Esc | Back to the grid |

## In the slideshow

| Key | Action |
|---|---|
| Space | Pause and go on |
| →, Page Down | Next image |
| ←, Page Up | Previous image |
| Esc (or a double click) | End the slideshow |

## In the editor

| Key | Action |
|---|---|
| V | Select |
| M | Selection (a part of the image) |
| A, L, P | Arrow, Line, Freehand |
| R, E | Rectangle, Ellipse |
| H, S | Highlighter, Spotlight |
| T, U, N | Text, Speech bubble, Step numbers |
| K, Z, B | Stamps, Magnifier, Cover |
| C | Crop and rotate |
| I | Eyedropper on the image |
| Shift+I | Eyedropper anywhere on the screen |
| Alt+click | Take a colour and keep the drawing tool |
| Shift while drawing | A square or a circle |
| Del | Delete the object selected |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+C | Copy the result (with Selection, the part chosen) |
| Ctrl+X, Ctrl+V | With Selection: cut the part, paste it as an object |
| Ctrl+R, Ctrl+Shift+R | Turn right, left |
| Ctrl+Alt+I | Resize the image (see [Editing an image](editor.md)) |
| Shift+wheel | With Crop and rotate: turn by 0.1° |
| Enter | With Crop and rotate: apply the crop |
| + and −, 0 | Zoom in and out, everything in view |
| Ctrl+S | Save copy, or Overwrite the original when chosen in the Options (see [Saving an edited image](editor-save.md)) |
| Ctrl+Shift+S | Save as |
| Esc | One step at a time: stops what is under way, ends the text, lets go of the selection; then closes the editor |

See [Editing an image](editor.md).

## In other pages

- **Save as**: **Esc** closes the page without saving.
- **Find duplicates**: **↑** and **↓** move between the copies, **Space** ticks or unticks, **Esc** closes. Enter does not delete.
