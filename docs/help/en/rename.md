# Renaming and new folders

Gives a file or a folder a new name, and makes new folders: on this computer, on disks, phones and servers.

## Renaming

1. Select the file or folder in the grid, or open the image in the viewer.
2. Press **F2**, or click ![Rename…](icon://text-cursor-input) in the toolbar, or choose **File > Rename…**, or right-click it and choose **Rename…**. A folder of the tree on the left is renamed from its right-click menu.
3. The **New name** window opens with the old name, selected without the extension, so you can type the new one straight away.
4. Press **Enter** or click **Rename**. **Esc** or **Cancel** leaves it as it was.

EyeCanSee checks the name while you type: it cannot be empty, contain `/` or `\`, or be the name of another item of the same folder. A red line says what is wrong, and Rename stays off until it is fixed.

## Things to know about renaming

- Rename works on one item at a time: with several selected it is off, and pointing at the button says why.
- The top folder of a disk, phone or server, the storages of a phone and the items inside a trash cannot be renamed.
- On a server the server itself renames the item, also a folder, so it is quick.

## New folder

1. Open the folder where the new one should go.
2. Press **Ctrl+Shift+N**, or click ![New folder…](icon://folder-plus) in the toolbar, or choose **File > New folder…**, or right-click an empty spot of the grid and choose **New folder…**.
3. The name is already written ("New folder", with " (2)" when it is taken) and selected: type the one you want.
4. Press **Enter** or click **Create**. The new folder is selected in the grid.

To make a folder inside another one without opening it, right-click that folder (in the grid or in the tree) and choose **New folder inside…**.

## Things to know about new folders

- The name is checked as for Rename.
- No folder can be made inside a trash, or on the list of a phone's storages: open one of the storages first.
- New folder is for the grid: in the viewer go back to the grid first.
